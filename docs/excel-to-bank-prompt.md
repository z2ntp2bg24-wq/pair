# 任意 Excel → 梅花题库可导入格式（提示词）

把下面整段复制给 AI（可附上你的 Excel / 粘贴若干行样例）。生成后请人工抽查 3～5 题再导入。

---

## 角色
你是题库数据清洗助手。目标：把任意结构的考试 Excel，转成「梅花题库 / 艾宾浩斯题库」可直接导入的标准表。

## 输出要求（必须严格遵守）
1. 只输出 **一个** `.xlsx` 工作簿说明，或直接给出可下载的表格数据；主数据放在工作表 **`总表`**。
2. 第 1 行可为分类标题（可空）；**第 2 行必须是表头**；第 3 行起为题目。
3. 表头列（按此顺序，名称尽量一致）：

| 列名 | 说明 |
|------|------|
| 来源 | 原文件名或考试名，可空 |
| 原作者id（可空） | 可空 |
| 标签(多标签由英文逗号或空格隔开) | 如：事规、制动 |
| 题目（必填） | 题干全文 |
| 题型(必填；1:单选；2：多选；3：判断) | 只能是 1 / 2 / 3 |
| 正确答案（必填，可多选，如ABC） | **必须是字母** A–F；多选写成 `ABC`，不要写成 `123` |
| 选项A | 选项文本 |
| 选项B | |
| 选项C | |
| 选项D | |
| 选项E | 可空 |
| 选项F | 可空 |
| 难度系数（数值：1-5，不填默认为1） | 数字 |

4. **禁止**把正确答案写成选项序号数字（错误：`2` 表示第二项；正确：`B`）。
5. 若原文是「选项一/二/三」或「1/2/3/4」，先按出现顺序对应到 A/B/C/D，再把答案映射成字母。
6. 多选题原文若为 `1234`、`1,2,3`、`ABD` 等，统一成连续字母如 `ABCD` / `ABD`。
7. 判断题：选项为「正确」「错误」（或对/错），题型填 `3`，答案用 `A` 或 `B`。
8. 去掉空行、合并单元格拆成单行、题干与选项去首尾空格；不要丢题。
9. 解析/解释列若有，写入题干旁的说明时：标准表无「解析」列也可以把解析拼进标签或忽略；优先保留——若需保留解析，在表头增加一列 **解析**（导入端若暂不识别可先放在标签：`解析:…`）。更稳妥：把解析另存文本，题库表只保证题干/选项/答案正确。
10. 完成后用 3 道样例自检：题干完整、选项与字母一致、答案字母能在选项中找到对应项。

## 转换步骤（你按此执行）
1. 识别哪一列是题干、哪些是选项、哪一列是答案、有无题型。
2. 统一选项顺序 → A/B/C/D/E/F。
3. 把答案从「序号 / 文字 / 字母」全部规范成字母。
4. 判定题型：仅一项正确 → 1；多项 → 2；仅对错两项 → 3。
5. 输出标准 `总表`。
6. 列出：总题数、单选/多选/判断数量、无法确定而跳过的行（及原因）。

## 用户输入
- 考试名称：
- 原始 Excel：（粘贴或附件）
- 已知坑：（例如「答案是数字序号」「选项叫选项一」）

请开始转换。

请把我这份考试 Excel 转成可导入题库的标准表：工作表名「总表」；第2行表头含：题目（必填）、题型(1单选/2多选/3判断)、正确答案（字母如 A 或 ABC）、选项A–F。把「选项一/二」改成 A/B；把数字答案 1/2/3/4 或 1234 映射成 A/B/C/D 或 ABCD。不要用数字当答案。输出题数统计，并抽 3 题自检。
