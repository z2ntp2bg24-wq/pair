# 艾宾浩斯题库 PWA（离线优先 · 多考试）

手机 + 离线为核心。IndexedDB + Service Worker，**不依赖 Streamlit / 隧道**。

## 功能

- **多考试卡片**：每个考试独立题库、复习进度、错题本
- 预置约 **2500** 题（首次导入「默认题库」）
- SM-2 间隔重复；每题时间可选（5–60 秒或不限时，默认 10 秒）；做题/背题都有「题板」可跳题；点选即提交；答错约停顿 5 秒后自动下一题
- 错题本导出（Excel / 文本 / 分析稿 / 复制给 AI）
- 导入 Excel 自动去重；题库页可「清除重复题」
- 黑白直角卡片 UI；底部导航（进入考试后）常驻

## 考试怎么用

1. 首页列出所有考试卡片（总数 / 剩余）
2. **新建考试** → 空卡片；点卡片进入该考试
3. 进入后底部：今日 / 练习 / 错题 / 题库 / 导入（均只作用于当前考试）
4. 顶栏 **← 考试** 返回列表；长按卡片或点「重命名 / 删除」管理考试


## 已导入多份题库怎么拆成考试？

若手机上已经把两份（或多份）xlsx 导进同一个库：

1. 刷新页面以加载最新 PWA（缓存 `ebbinghaus-pwa-v8`）
2. 点进任意考试卡片 → **题库** → **清除重复题**（去掉同文件重复导入）
3. 返回考试列表（← 考试）→ **按来源拆成考试**
   - 按每题的 `source_file`（导入时的 xlsx 文件名）分组
   - 为每个文件名建一张考试卡片并移入题目
   - 若所有题的文件名都相同：无法拆分，toast 会说明；此时请「新建考试」后分别重新导入两份文件
4. 之后每个考试独立复习 / 错题 / 导入

新导入会写入 `source_file=文件名` 与 `import_batch=时间戳`，方便以后再拆。

## 去重

- 规则：题干 trim+合并空白 + 答案 trim+小写字母 → 相同视为重复
- **导入**时跳过当前考试已有及文件内重复
- **题库 → 清除重复题**：保留最早 id，删除其余并清理孤儿复习/错题记录

## IndexedDB 迁移（v1 → v2）

旧版单库用户升级后：

1. 自动创建 `decks` 与默认考试「默认题库」
2. 已有题目写入 `deck_id`（不重新下载，不复制题目）
3. `preload_v1` 已存在且有题目时，不再二次导入 `questions.json`

## 本地启动

```bash
cd /workspace/ebbinghaus-pwa
python3 -m http.server 8080
```

打开 `http://<主机IP>:8080/`（Streamlit 8501 可并行）。

Service Worker 缓存名：`ebbinghaus-pwa-v8`。

```bash
python3 export_questions.py
```

## 手机

首次联网打开以缓存资源与 SheetJS；然后可「添加到主屏幕」，断网刷题。

## 云同步（手机 ↔ 桌面）

1. 任意一端打开 **考试列表 / 今日 / 题库** → 「云同步」→ **生成本机同步码** → 复制
2. 另一端 **输入同步码** → **绑定**
3. 在线时自动拉取/合并（整库快照 LWW）；本地改动约 2 秒后推送；可点「立即同步」
4. **同步码即密钥**：勿分享。无账号密码（v1）
5. Service Worker：`ebbinghaus-pwa-v16`；`/api/sync` 不走缓存

API：`GET|PUT /api/sync`，请求头 `X-Pair-Sync-Code`。数据存 Cloudflare KV（密钥 SHA-256）。
